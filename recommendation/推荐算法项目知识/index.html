    MLP：全连接神经网络，Fully Connected Layer

    推荐系统通常分为

    \[ \text{全量物品库} \rightarrow \text{召回} \rightarrow \text{粗排/精排} \rightarrow \text{重排} \rightarrow \text{最终推荐} \]

    指标

    AUC

    AUC：Area Under Curve

    衡量：随机抽一个正样本和一个负样本，模型把正样本排在前面的概率

    \[ \boxed{\text{AUC} = \frac{\#\{(s_{u,i} > s_{u,j}) \mid y_{u,i}=1, y_{u,j}=0\}}{\#\text{所有正负样本对}}} \]

    好处：它只关心 正负样本对之间的排序，不直接受正负样本数量比例影响

    具体例子：

    假设某个推荐模型对 5 篇文章打分如下

    文章 真实标签 模型预测分数
    A 1 0.90
    B 1 0.70
    C 0 0.80
    D 0 0.40
    E 0 0.30

    正样本有 2 个：A、B；负样本有 3 个：C、D、E，故 AUC 的分母为 6

    遍历所有正样本：

    • A：
    正样本 负样本 比较 是否排序正确
    A C 0.90 > 0.80 正确
    A D 0.90 > 0.40 正确
    A E 0.90 > 0.30 正确
    • B：
    正样本 负样本 比较 是否排序正确
    B C 0.70 < 0.80 错误
    B D 0.70 > 0.40 正确
    B E 0.70 > 0.30 正确

    因此 AUC 的分子为 5，从而 \(\text{AUC} = \frac 56 \approx 0.8333\)

    代码 1，暴力解法，时间 \(O(n^2)\)，空间 \(O(n)\)

    def auc_bruteforce(labels, scores):
    positive_scores = []
    negative_scores = []

    # 1.分离正负样本
    for label, score in zip(labels, scores):
        if label == 1:
            positive_scores.append(score)
        else:
            negative_scores.append(score)

    num_positive = len(positive_scores)
    num_negative = len(negative_scores)

    if num_positive == 0 or num_negative == 0:
        return 0.0  # undefined case in practice

    # 2. pairwise comparison
    correct_pairs = 0.0

    for pos_score in positive_scores:
        for neg_score in negative_scores:
            if pos_score > neg_score:
                correct_pairs += 1
            elif pos_score == neg_score:
                correct_pairs += 0.5

    # 3. normalization
    return correct_pairs / (num_positive * num_negative)

    GAUC

    \[ \boxed{ \text{GAUC} = \frac{\sum_u w_u \cdot \text{AUC}_u}{\sum_u w_u} } \]

    其中：\(w_u\) 为该用户候选对数

    该用户样本中“所有正样本与所有负样本组成的样本对（Pair）的总数

    在 AUC 的例子中，为 6

    Recall@K 召回率

    衡量：真实喜欢的东西，有多少被你找回来了

    \[ \boxed{ \text{Recall@K}=\frac{|R_K \cap G|}{|G|} } \]

    召回阶段核心指标，强调的是不要漏掉

    Precision@K 准确率

    衡量：推荐的 K 个里，有多少是用户真正喜欢的

    \[ \boxed{ \text{Precision@K}=\frac{|R_K \cap G|}{K} } \]

    排序阶段常用，强调别乱推荐

    Hit Rate@K 命中率

    衡量：Top-K 是否至少命中一个正样本

    \[ \boxed{ \text{HitRate@K}= \begin{cases} 1, & |R_K \cap G|>0 \\ 0, & \text{otherwise} \end{cases} } \]

    MRR 平均倒数排名

    衡量：第一个正样本排得有多靠前

    \[ \boxed{ \text{MRR} = \frac{1}{N} \sum \frac{1}{\text{rank}_i} } \]

    如果某个用户没有命中，则 \(\text{rank} = \infty\)，\(1/\text{rank} = 0\)

    NDCG@K

    归一化折损累积增益（@K）。NDCG：Normalized Discounted Cumulative Gain

    \[ \boxed{ \text{NDCG}@K = \frac{\text{DCG}@K}{\text{IDCG}@K} } \]

    DCG@K

    \[ \text{DCG}@K = \sum_{i=1}^{K} \frac{\text{rel}_i}{\log_2(i+1)} \]

    关于 \(\text{rel}_i\)：第 \(i\) 个位置的相关性（gain），可以是：

    • 二值相关性，即 \(\text{rel}_i \in \{0,1\}\)
    • 分级相关性 \((0,1,2,3,\ldots)\)

    \(\log_2(i+1)\)：位置折损（越靠后权重越低）

    具体例子

    假设用户真实行为：点了 \(i_2\)、\(i_4\)；买了 \(i_6\)

    定义：click = 1、purchase = 3

    推荐列表为

    rank item 行为 rel_i
    1 \(i_1\) 无 0
    2 \(i_6\) purchase 3
    3 \(i_2\) click 1
    4 \(i_9\) 无 0

    虽然用户点击了 \(i_4\)，但不在列表中，所以不用管。此时

    \[ \text{DCG} = \frac{3}{\log_2(3)} + \frac{1}{\log_2(4)} \approx 2.3928 \]

    IDCG

    对于 ideal DCG，需要构造最优排序序列

    排序原则：rel 从大到小排序

    具体例子

    承接 DCG 中的例子。根据 排序原则 可以构造

    rank item rel
    1 \(i_6\) 3
    2 \(i_2\) 1
    3 \(i_4\) 1

    此时

    \[ \text{IDCG} = \frac{3}{\log_2(2)} + \frac{1}{\log_2(3)} + \frac{1}{\log_2(4)} \approx 4.1310 \]

    得到 NDCG 为

    \[ \text{NDCG} = \frac{\text{DCG}}{\text{IDCG}} = 0.5792 \]

    CTR 点击率

    CTR：Click-Through Rate

    衡量：推荐系统把内容“展示出来之后，有多少被用户点了”

    \[ \boxed{ \text{CTR} = \frac{\text{用户点击次数}}{\text{曝光次数}} }= \frac{\text{click}}{\text{impression}} \]

    具体例子

    某用户一天，系统展示了 100 个推荐 item（\(\text{mpression} = 100\)），用户点了其中 8 个（\(\text{click} = 8\)），此时 \(\text{CTR} = 8 \%\)

    CVR 转化率

    CVR：Conversion Rate

    Conversion：转化，用户完成了期望的特定行为。如“浏览 / 点击”转变为“购买 / 下载 / 注册”等

    \[ \boxed{ \text{CVR} = \frac{\text{转化次数}}{\text{点击次数}} }= \frac{\text{purchase}}{\text{click}} \]

    转化的具体内容

    • 电商推荐：下单（purchase）、支付成功

    • 广告系统：注册、 下载、填表、购买

    与 CTR 的关系：

    \[ \text{曝光 (Impression)} \xrightarrow{\text{CTR}} \text{点击 (Click)} \xrightarrow{\text{CVR}} \text{转化 (Conversion)} \]

    召回覆盖率

    真实用户后来交互的物品，有多少被召回进了候选集

    设考虑用户 \(u\)，召回候选集为 \(C_u\)，真实测试物品集合为 \(T_u\)（在项目中只有一个），则

    \[ \boxed{ \text{Coverage} = \frac{ \sum_u |C_u \cap T_u| }{ \sum_u |T_u| } } \]
    \[ \text{覆盖率} = \frac{ \text{被候选集命中的真实正样本数} }{ \text{所有真实正样本数} } \]

    真实正样本 含义：

    真实：指它来自真实日志/测试集，不是模型猜的。在项目中：指用户后面实际交互过的文章

    正样本：指标签为 \(1\) 的样本，也就是交互了的物品

    如用户 \(u\) 后来真的看了文章 \(i\)，那么 \((u,i)\) 是正样本，即 \(y_{u,i} = 1\)

    如果用户 \(u\) 后来没有看过文章 \(j\)，则 \((u,j)\) 称为负样本，即 \(y_{u,j}=0\)

    YoutubeDNN

    目标不是为了直接精细预测某个用户是否会点击某篇文章，而是从全量文章库中，快速召回用户可能感兴趣的 Top-K 篇文章

    定义召回分数

    \[ s(u,i) = \boldsymbol{z}_u^\top \boldsymbol{v}_i \]

    分数越高，说明用户向量 \(\boldsymbol{z}\) 和文章向量 \(\boldsymbol{v}_i\) 越接近，文章越可能被召回

    最终召回结果是：

    \[ \operatorname{Recall}(u) = \operatorname{TopK}_{i\in \mathcal I} \boldsymbol{z}_u^\top \boldsymbol{v}_i \]

    其中 \(\mathcal I\) 表示全量文章集合。公式表示：通过计算用户与所有文章（即 \(i\in \mathcal I\)）的匹配度，为用户 \(u\) 筛选出最感兴趣的 \(K\) 篇文章作为最终召回的结果

    LR

    Logistic Regression，逻辑回归

    用于二分类问题，比如推荐系统中的 CTR 预估：

    \[ y = \begin{cases} 1, & \text{用户点击} \\ 0, & \text{用户未点击} \end{cases} \]

    模型的目标是预测：

    \[ \hat y = P(y=1 \mid x) \]

    即给定一个样本特征 \(x\)，预测它属于正类的概率

    例如：样本可能是

    用户：user_id = 1024
物品：item_id = 889
类别：category = 科技
设备：device = iPhone
时间：hour = 21
标签：click = 1

    LR 就是根据这些特征预测出 \(P(\text{click}=1)\) 的大小

    不使用线性回归的原因

    最朴素的模型是线性模型

    \[ z = w^\top x + b \]
    • \(x\)：输入特征
    • \(w\)：是特征权重
    • \(b\)：是偏置
    • \(z\)：是线性打分

    \(z\) 的取值范围是 \((-\infty, +\infty)\)，并不是概率的区间。此时使用 Sigmoid 函数 将 \(\mathbb R \rightarrow [0,1]\)

    LR 的预测形式：

    \[ \boxed{ \hat y = \sigma(w^\top x + b) } \]

    其中

    \[ \sigma(z)=\frac{1}{1+e^{-z}} \]

    如果某个 \(w_i > 0\)，说明这个特征会提高点击概率

    如果某个 \(w_i < 0\)，说明这个特征会降低点击概率

    因此 LR 的优点是可解释性比较强，每个特征的权重都可以解释为它对最终点击概率的贡献

    假设有 \(n\) 个特征：

    \[ x = [x_1, x_2, x_3, \dots, x_n] \]

    则 LR 的线性部分是

    \[ w^\top x + b = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b \]

    损失函数

    对于一个样本，交叉熵损失 为

    \[ L(y,\hat y) = -\left[ y\log \hat y + (1-y)\log(1-\hat y) \right] \]

    • 若真实标签是点击（\(y=1\)），此时

      \[ L = -\log \hat y \]

      \(\hat y\rightarrow 1\) 时，\(L\) 会变小，所以模型希望 \(\hat y\) 越接近 1 越好

    • 若真实标签是未点击（\(y=0\)），此时

      \[ L = -\log(1-\hat y) \]

      希望 \(\hat y\) 越接近 0 越好

    交叉熵作用：预测概率越接近真实标签，损失越小；预测越离谱，损失越大

    对于所有训练样本，整体损失是：

    \[ \mathcal L(w,b) = -\sum_{i=1}^{N} \left[ y_i\log \hat y_i + (1-y_i)\log(1-\hat y_i) \right] \]

    LR 的训练目标是找到最优参数 \(w,b\)，使损失函数最小

    \[ \min_{w,b} \mathcal L(w,b) \]

    常见训练方法有：梯度下降、随机梯度下降 SGD、mini-batch SGD、L-BFGS、牛顿法或拟牛顿法

    局限性：不能自动学习特征交叉

    LR 依赖人工特征工程，不能自动学习复杂特征交叉

    例如：

    \[ \text{用户喜欢篮球} \times \text{文章类别是体育} \]

    LR 默认不会自动建模这个组合，只能分别学习

    \[ w_1 x_{\text{用户喜欢篮球}} \quad w_2 x_{\text{文章类别是体育}} \]

    如果想让 LR 学到这个关系，就必须人工构造交叉特征

    \[ x_{\text{用户喜欢篮球 } \times \text{ 文章类别是体育}} \]

    反向传播

    概述

    前向传播：负责“算预测值”
反向传播：负责“算参数该怎么改”

    前面学习的是 LR 的前向传播，会用到参数 \(w,b\)，反向传播的目标 是求 \(\frac{\partial L}{\partial w}, \frac{\partial L}{\partial b}\)，然后用 梯度下降 更新参数

    \[ \boxed{ \frac{\partial L}{\partial w} = (p-y)x,\quad \frac{\partial L}{\partial b} = p-y} \]

    计算过程：

    设损失函数

    \[ L = - \left[ y\log p + (1-y)\log(1-p) \right] \]

    对预测概率 \(p\) 求偏导得：

    \[ \frac{\partial L}{\partial p} = - \left[ \frac{y}{p} - \frac{1-y}{1-p} \right]=\frac{p-y}{p(1-p)} \]

    这里将损失函数视为 \(L = L(y,p)\)，因此为偏导

    设 sigmoid 函数为

    \[ p = \sigma(z)=\frac{1}{1+e^{-z}} \]

    对其求导：

    \[ \frac{\partial p}{\partial z} = -(1+e^{-z})^{-2}\cdot (-e^{-z}) = (1-p)\cdot p \]

    用导数当然也可以，这里只是统一写成了偏导的形式

    再考虑线性部分求导。由于 \(z = w^\top x+b\)，则

    \[ \frac{\partial z}{\partial w_j}=x_j, \quad \frac{\partial z}{\partial b}=1 \]

    由链式法则：

    \[ \frac{\partial L}{\partial w_j} = \frac{\partial L}{\partial p} \cdot \frac{\partial p}{\partial z} \cdot \frac{\partial z}{\partial w_j} = \frac{p-y}{p(1-p)} \cdot p(1-p) \cdot x_j=(p-y)x_j \]

    由于 \(p-y\) 为标量，写成向量形式为

    \[ \frac{\partial L}{\partial w} = \begin{bmatrix} \frac{\partial L}{\partial w_1}\\ \frac{\partial L}{\partial w_2}\\ \vdots\\ \frac{\partial L}{\partial w_n} \end{bmatrix} = (p-y) \begin{bmatrix} x_1\\ x_2\\ \vdots\\ x_n \end{bmatrix} = (p-y)x \]

    同理，对于偏置项（\(b \in\mathbb R\)）：

    \[ \frac{\partial L}{\partial b} = \frac{\partial L}{\partial p} \cdot \frac{\partial p}{\partial z} \cdot \frac{\partial z}{\partial b} = \frac{p-y}{p(1-p)} \cdot p(1-p) \cdot 1=p-y \]

    设 \(X\in \mathbb{R}^{m \times n}\)，考虑第 \(i(i=1,\ldots,m)\) 个样本 \(x_i^\top\)：

    \[ \frac{\partial L_i}{\partial w_j} = (p_i-y_i)x_{ij},\quad j =1 , \ldots, n \]

    更新：

    \[ w_j \leftarrow w_j - \eta (p_i-y_i)x_{ij} \]
    \[ b \leftarrow b-\eta(p_i-y_i) \]

    向量形式：

    \[ \frac{\partial L_i}{\partial w} = (p_i-y_i)x_i \]

    其中

    \[ x_i = [x_{i1},x_{i2},\dots,x_{in}]^\top \]

    即取出数据矩阵 \(X\) 的第 \(i\) 行（按样本来划分）后转置为列向量

    \[ \frac{\partial L_i}{\partial w} = \begin{bmatrix} (p_i-y_i)x_{i1}\\ (p_i-y_i)x_{i2}\\ \vdots\\ (p_i-y_i)x_{in} \end{bmatrix} \]

    具体例子

    1. 情况一：真实点击了（\(y=1\)），但模型预测低（设 \(p=0.2\)）

      \(p-y=-0.8\)，即 \(w_j \leftarrow w_j + 0.8 \eta x_j\)。故如果某个特征 \(x_j>0\)，它对应的权重会被增大

      直观：这个样本本来应该被推荐得更靠前，但模型给 低了，所以模型会提高相关特征的权重

    2. 情况二：真实没点击（\(y=0\)），但模型预测高（设 \(p=0.8\)）

      \(p-y=0.8\)，即 \(w_j \leftarrow w_j - 0.8\eta x_j\)

      直观：这个物品用户没点，但模型给了高分，所以模型会降低相关特征的权重

    多个样本时

    假设有 \(m\) 个样本，总损失一般写成平均损失：

    \[ L=\frac{1}{m}\sum_{i=1}^m L_i \]
    \[ \frac{\partial L}{\partial w_j} = \frac{1}{m}\sum_{i=1}^m (p_i-y_i)x_{ij} \]
    \[ \frac{\partial L}{\partial b} = \frac{1}{m}\sum_{i=1}^m (p_i-y_i) \]

    向量形式

    \[ \frac{\partial L}{\partial w} = \frac{1}{m}X^\top(p-y) \]

    LR 的反向传播代码（我：字节 26-06-08 一面手撕）

    import numpy as np

class LogisticRegression:
    def __init__(self, lr=0.1, epochs=1000):
        self.lr = lr
        self.epochs = epochs
        self.w = None
        self.b = None

    def sigmoid(self, z):
        return 1 / (1 + np.exp(-z))

    def fit(self, X, y):
        # X: (m, n)
        # y: (m,)
        m, n = X.shape

        self.w = np.zeros(n)
        self.b = 0.0

        for _ in range(self.epochs):
            # 前向传播
            z = X @ self.w + self.b
            p = self.sigmoid(z)

            # 反向传播
            dz = p - y
            dw = (X.T @ dz) / m
            db = np.sum(dz) / m

            # 参数更新
            self.w -= self.lr * dw
            self.b -= self.lr * db

    def predict_proba(self, X):
        z = X @ self.w + self.b
        p = self.sigmoid(z)
        return p

    def predict(self, X):
        p = self.predict_proba(X)

    FM

    Factorization Machine 因子分解机

    在 LR 的基础上，自动加入“二阶特征交叉”的模型

    为了让模型学习两个特征之间的关系，可以在线性模型后面加上二阶交叉项，但是这样参数很多

    表达式

    \[ \hat y = w_0 + \sum_{i=1}^n w_i x_i + \sum_{i<j}\langle v_i,v_j\rangle x_i x_j \]

    FM 算法需要学习：全局偏置 \(w_0\)、 一阶特征权重 \(w_i\)、 特征 embedding 向量 \(v_i\)

    参数量：\(O(nk)\)

    下述模型的参数量为 \(O(n^2)\)

    \[ y = w_0 + \sum_{i=1}^{n} w_i x_i +\sum_{i<j}\langle v_i,v_j\rangle w_{ij}x_i x_j \]

    FM 的数学变形

    \[ \sum_{i=1}^{n-1}\sum_{j=i+1}^{n} \langle v_i, v_j\rangle x_i x_j = \frac{1}{2} \sum_{f=1}^{k} \left[ \left( \sum_{i=1}^{n} v_{i,f}x_i \right)^2 - \sum_{i=1}^{n} v_{i,f}^2x_i^2 \right] \]

    局限性：主要处理的是 二阶交叉，对更复杂的高阶组合表达能力有限

    embedding 向量

    \(k\) 是 embedding 向量的维度（隐向量维度），人为设置，远小于 \(n\)

    在 FM 中，每一个特征 \(x_i\) 都对应一个向量 \(v_i \in \mathbb R^k\)

    \(k\) 的大小对模型的影响：

    • 如果 \(k\) 太小，模型表达能力弱，可能学不到复杂关系

    • 如果 \(k\) 太大，参数更多，容易过拟合，训练也更慢

    查表操作

    用户 ID 通过 embedding 得到用户静态向量

    \[ u=E_{\text{user}}[\text{user\_id}] \]

    这里 \([\text{user\_id}]\) 是 查表操作。设共有 \(N\) 个用户，每个用户用一个 \(k\) 维向量表示，得到表：

    \[ E_{\text{user}}=\begin{bmatrix} u_1^\top \\ u_2^\top \\ \vdots \\ u_N^\top \end{bmatrix}\in \mathbb{R}^{N\times k} \]

    DNN

    DNN 负责学习高阶、非线性的特征交叉

    深度神经网络 Deep Neural Network

    一个 DNN 一般包括三部分

    输入层 → 隐藏层 → 输出层

    比如

    输入特征
   ↓
第 1 个隐藏层
   ↓
第 2 个隐藏层
   ↓
第 3 个隐藏层
   ↓
输出层

    本质上是一个由很多层组成的函数，输入特征 \(x\)，输出预测值 \(\hat y\)，可以简单理解为：

    \[ \hat y = f(x) \]

    只不过这个 \(f\) 不是简单的线性函数，而是很多层线性变换和非线性激活函数组合起来的复杂函数

    DNN 的想法：不只做一次线性变换，而是做很多次

    DNN的每一层

    1. 线性变换
    \[ z^{(l)} = W^{(l)}a^{(l)} + b^{(l)} \]
    • \(a^{(l)}\)：第 \(l\) 层的输入
    • \(W^{(l)}\)：权重矩阵
    • \(b^{(l)}\)：偏置

    • \(z^{(l)}\)：线性变换后的结果

    • 非线性激活

    \[ a^{(l+1)} = \sigma(z^{(l)}) \]

    不一定使用 Sigmoid，可以是 ReLU、Tanh 等。DNN 中，最常用的是 ReLU：

    \[ \text{ReLU}(x)=\max(0,x) \]

    用于引入非线性，否则多层线性变换叠加起来，还是一个线性变换

    线性层负责特征组合，激活函数负责引入非线性表达能力

    局限性：DNN 对低阶交叉，尤其是二阶交叉，不一定学得足够直接、稳定

    Embedding 层

    Embedding 层：嵌入层

    一个可训练的查表层。它把高维稀疏的 one-hot 特征，映射成低维稠密的 embedding 向量

    用途

    离散特征映射为稠密向量（线性变换）

    推荐系统里的输入特征通常是这种形式：

    user_id = 1024
item_id = 889
category = 科技
device = iPhone
hour = 21

    这些特征很多都是 离散类别特征。比如 user_id 可能有几十万、几百万个取值

    如果直接 one-hot 编码：

    \[ \text{user\_id}=1024 \quad \Rightarrow \quad [0,0,\dots,1,\dots,0] \]

    这个向量会非常长，而且大部分位置都是 0

    Embedding 层的作用就是把这个很长的 one-hot 向量，映射成一个短向量，例如

    \[ \text{user\_id}=1024 \quad \Rightarrow \quad e_{\text{user}=1024}\in \mathbb R^k \]

    设 \(k=8\)，则可能是：

    \[ e_{\text{user}=1024} = [0.12,\ -0.31,\ 0.08,\ 0.44,\ -0.25,\ 0.17,\ 0.03,\ 0.29] \]

    这个向量不是人工指定的，而是模型训练过程中学出来的

    数学表达

    假设某一类特征一共有 \(n\) 个可能取值，如用户 ID 有 \(n\) 个。Embedding 层本质上维护一个参数矩阵：\(E\in \mathbb R^{n\times k}\)

    • \(n\)：该特征一共有多少种取值
    • \(k\)：embedding 维度
    • 第 \(i\) 行 \(E_i\)：第 \(i\) 个特征取值对应的 embedding 向量

    设输入是第 \(i\) 个类别，它的 one-hot 向量记为列向量

    \[ x_i= [0,0,\dots,1,\dots,0]^\top \in\mathbb R^{n\times 1} \]

    embedding 查表可以写成

    \[ e_i = E^\top x_i \in \mathbb{R}^k \]

    这个乘法本质上就是取出矩阵 \(E\) 的第 \(i\) 行，再转置成列向量 \(e_i = E_{i,:}^\top\)

    Deep & Cross Network

    专门为推荐系统、广告点击率预估这类任务设计的模型，用来自动学习特征交叉，尤其是显式高阶特征交叉

    DCN 的输入一般也是推荐模型常见的形式：

    1. 类别特征先过 Embedding 层
    2. 数值特征归一化后与 1 中的向量拼接

    如年龄 23，归一化为 0.23

    1. 得到统一输入向量

    然后 \(\boldsymbol{x}_0\) 同时进入两个分支，表示为如下图示

    Cross Network 负责显式交叉，Deep Network 负责隐式非线性表达

    Cross Network 每加深一层，就会把交叉阶数提高一阶

    Cross Network 是 DCN 的核心

    如果 Cross Network 有 \(L\) 层，那么它最多可以显式建模到 \(L+1\) 阶特征交叉

    层数记号：

    • Cross Network 堆叠了 \(L_1\) 层交叉层（Cross Layer），输出 \(\boldsymbol{x}_{L_1}\)

    • Deep Network 堆叠了 \(L_2\) 层普通全连接层（DNN Layer），它的最终输出叫做 \(\boldsymbol{h}_{L_2}\)

    拼接：

    算法最后要拼接 \(\boldsymbol{x}_{L_1}\)、\(\boldsymbol{h}_{L_2}\) ：

    \[ \boldsymbol{z} = [\boldsymbol{x}_{L_1}^\top, \boldsymbol{h}_{L_2}^\top]^\top \]

    再送入逻辑回归层得到点击概率：

    \[ p = \sigma(\boldsymbol{w}_{\text{logits}}^T \boldsymbol{z} + b) \]

    对比 DeepFM

    DeepFM 里面的高阶交叉主要靠 DNN 隐式学习。DNN 虽然可以学习高阶交叉，但它学到的交叉不够显式，不容易解释

    Cross Network

    Cross Layer 是 Cross Network 的一个处理单元

    原理：用原始特征 \(x_0\) 去不断调制（modulate）当前表示 \(x_l\)。不是 组合爆炸

    在数学上，是一个向量（下式中的 \(x_{l+1}\)）

    公式为

    \[ x_{l+1}=x_l+x_0(x_l^\top w_l)+b_l \]
    • \(x_0\)：最原始的输入特征向量
    • \(x_l\)：第 \(l\) 层 Cross Network 的输出
    • \(w_l\)：第 \(l\) 层的权重向量
    • \(b_l\)：偏置
    • \(x_{l+1}\)：下一层输出

    具体例子（产生特征交叉）

    设输入向量：\(x_0 =[x_1,x_2,x_3]^\top\)

    第一层时：

    \[ x_1=x_0+x_0(x_0^\top w_0)+b_0 \]

    其中：

    \[ x_0^\top w_0 =w_1x_1+w_2x_2+w_3x_3 \]
    \[ x_0(x_0^\top w_0) = \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} (w_1x_1+w_2x_2+w_3x_3) = \begin{bmatrix} w_1x_1^2+w_2x_1x_2+w_3x_1x_3 \\ w_1x_2x_1+w_2x_2^2+w_3x_2x_3 \\ w_1x_3x_1+w_2x_3x_2+w_3x_3^2 \end{bmatrix} \]

    此时已出现了二阶特征交叉

    第 \(l+1\) 层输出理论上会包含所有 \(l+1\) 次的单项代数式

    \[ x_1^{m_1} x_2^{m_2} \dots x_d^{m_d},\quad m_1+m_2+\dots+m_d = l+1 \]

    但由于 \(x_0^\top w_0 \in \mathbb{R}\)，并不是在枚举所有高阶单项式（不会生成这些独立的向量）。隐式表达高阶特征交叉

    Deep Network

    类似 DeepFM 的 DNN 部分

    目的：捕捉特征之间的复杂非线性关系，这些关系可能不是 Cross Network 显式交叉能覆盖的

    位置：Deep Network 与 Cross Network 并行，输入同样是 \(x_0\)

    输出：一个向量 \(h_{L_2}\)，表示 Deep Network 提取的高阶非线性特征

    Deep Network 本质是一个标准的全连接神经网络（MLP）：

    \[ \begin{aligned} h_1 &= \sigma(W_1 x_0 + b_1) \\ h_2 &= \sigma(W_2 h_1 + b_2) \\ &\ \vdots \\ h_{L_2} &= \sigma(W_{L_2} h_{L_2-1} + b_{L_2}) \end{aligned} \]
    • MLP：Fully Connected Layer

    向量级交互

    DCN 是将向量拼成一个很长的向量，而 CIN 网络保留了向量的结构

    CIN

    CIN 第一层

    假设 CIN 输入是：

    \[ X_0 = \begin{bmatrix} e_1 \\ e_2 \\ e_3 \end{bmatrix} \in \mathbb{R}^{3\times D} \]

    第一层 CIN 会让上一层输出 \(X_0\) 和原始输入 \(X_0\) 做两两交互

    \[ e_i \circ e_j, \quad i,j = 1,\ldots,D \]

    共 9 种交互向量，得到的结果仍为 \(D\) 维向量

    压缩

    如果把所有交互向量都保留下来，数量会越来越多

    做法：先生成大量交互向量，再通过加权求和，把它们压缩成固定数量的新向量

    假设第一层想输出 \(H_1\) 个新向量，那么 \(X_1 \in \mathbb{R}^{H_1 \times D}\)

    设输入矩阵：\(X_0 \in \mathbb{R}^{m \times D}\)

    \[ X_{h,*}^{1} = \sum_{i=1}^{m} \sum_{j=1}^{m} W_{i,j}^{1,h} ( X_{i,*}^{0} \odot X_{j,*}^{0} ) \]

    \(W^1 \in \mathbb{R}^{m \times m \times H_1}\) 是三维张量，但是 \(W^{1,h}\in \mathbb{R}^{m \times m}\)

    \(W_{i,j}^{1,h}\) 是标量，可学习的标量参数

    CIN 的第 \(k\) 层

    第 \(k\) 层输入是上一层的输出 \(X_{k-1} \in \mathbb{R}^{H_{k-1}\times D}\)。CIN 每一层都让 \(X_{k-1}\) 与 \(X_{0}\) 作交互

    第 \(k\) 层第 \(h\) 个输出向量为

    \[ X_{h,*}^{k} = \sum_{i=1}^{H_{k-1}} \sum_{j=1}^{m} W_{i,j}^{k,h} ( X_{i,*}^{k-1} \odot X_{j,*}^{0} ) \]

    CIN 每一层都会得到 \(X_k \in \mathbb{R}^{H_k\times D}\)，按行求和，得到 \(p_k\)，即

    \[ p_{k,i} = \sum_{d=1}^{D} X_{i,d}^{k} \]

    每一层都如此操作，得到：

    \[ p^{+}=[p_1, p_2, \dots, p_T] \]

    \[ \cdots \]
    \[ h_{L}=\sigma(W_Lh_{L-1}+b_L) \]

    它负责隐式学习高阶非线性关系

    DIN

    DIN 核心：候选物品激活历史行为

    传统平均池化存在多峰兴趣消融现象

    属于堆叠架构

    Local Activation（局部激活）：针对当前候选商品，只激活用户历史行为中与它相关的部分，而不是把所有的历史行为都同等看待

    针对当前候选物品动态生成的 用户兴趣向量 为

    \[ v_U(A) = \sum_{i=1}^{H} w_i e_i \]

    其中：\(e_i\) 是用户第 \(j\) 个历史行为的嵌入向量。权重的计算公式：

    \[ w_i = a(e_i, v_A) \]

    公式中 \(a(\cdot)\) 是一个函数，由多层感知机 MLP 实现的注意力网络

    我的项目例子

    项目中召回阶段候选集的大小为 300，即文章 \(A_1,A_2, \ldots, A_{300}\)，取其中一篇文章作为候选文章（即待打分的文章），设为 \(A\)

    候选文章的嵌入向量为 \(e_A\)（12 维），用户历史序列为 \(e_i(1\leq i \leq 30)\)（已嵌入，12 维），构造向量

    \[ a_i = [e_A, e_i, e_A - e_i, e_A \circ e_i] \in \mathbb R^{48} \]

    经过两层神经网络：\(a_i \rightarrow \mathbb R^{64} \rightarrow \mathbb R^{32} \rightarrow \mathbb R\)，得到 attention 分数 \(s_i\)，再作 softmax 得到 \(w_i\)：

    \[ w_i = \frac{\exp(s_i)}{\sum_{k=1}^{30}\exp(s_k)} \]

    此时 \(v_U(A) = \sum_{i=1}^{30} w_i e_i\) 即为用户 \(u\) 对文章 \(A\) 的用户兴趣向量。

    Concat 后输入 MLP：

    \[ x=[x_{\text{dense}},u,e_A,v_U(A)] \]

    即

    [稠密数值特征，用户静态特征，候选物品特征，动态用户兴趣特征]

    Concat 把不同来源的特征向量横向拼接成一个更长的向量，然后送入 MLP

    GBDT 基线

    不用神经网络，而是用一堆决策树逐步修正预测误差的传统机器学习精排模型

    GBDT：Gradient Boosting Decision Tree，梯度提升决策树

    不是一次性训练一棵很强的树，而是训练很多棵弱树，让它们一棵一棵叠加起来，逐步逼近真实标签

    不擅长处理高维稀疏特征

    一棵树可以写成一个函数 \(f(x)\)，它接收样本特征 \(x\)，输出一个预测分数。GBDT 不是只用一棵树，而是用很多棵树叠加，再结合学习率：

    \[ F_M(x)=F_0(x)+ \eta \sum_{m=1}^{M} f_m(x) \]

    • \(F_M(x)\)：这里的 \(M\) 表示是加了 \(M\) 棵树

    • 最后输出点击率时，要将 \(F_M(x)\) 经过 sigmoid 后映射到 \([0,1]\)

    Boosting 思想

    设当前模型对第 \(i\) 个样本的预测为 \(F_{m-1}(x_i)\)，真实标签是 \(y_i\)，当前残差是：

    \[ r_i^{(m)}=y_i - F_{m-1}(x_i), \quad i = 1,2,\ldots,N \]

    第 \(m\) 棵树就去学习这个残差（第 \(m\) 棵树不是由某一个样本决定的，而是由所有样本的残差共同决定的）：

    \[ f_m(x_i) \approx r_i^{(m)}, \quad i = 1,2,\ldots,N \]

    即类似解

    \[ f_m = \arg\min_f \sum_{i=1}^{N} \left( r_i^{(m)}-f(x_i) \right)^2 \]

    然后更新模型：

    \[ F_m(x) = F_{m-1}(x) + \eta f_m(x) \]

    直观理解：当前模型哪里预测低了，新树就往上补；当前模型哪里预测高了，新树就往下修正。

    训练过程是：预测 → 计算误差 → 训练新树修正误差 → 更新预测，不断重复

    叶子节点数量

    在一般的 GBDT里，决策可以有很多叶子区域，设共有 \(J\) 个叶子节点，区域记为 \(R_1,R_2,\ldots,R_J\)，此时 \(f_m(x)\) 的表达式为

    \[ f_m(x)=\sum_{j=1}^{J}\gamma_j\mathbf{1}(x\in R_j) \]

    在项目中

    由于设置了 GBDT_MAX_DEPTH = 1，在我的程序中可以认为

    \[ f_m(x)= \gamma_1\mathbf{1}(x\in R_1) + \gamma_2\mathbf{1}(x\in R_2) \]

    CTR 场景

    推荐系统 CTR 预估是二分类问题 \(y \in \{0,1\}\)。GBDT 先输出一个分数 \(F(x)\)，通过 Sigmoid 转成点击概率。交叉熵损失为：

    \[ L=-\sum_{i=1}^{N}\left[y_i\log \hat y_i+(1-y_i)\log(1-\hat y_i)\right] \]

    这种情况下，负梯度可以理解为 \(g_i=y_i-\hat y_i\)，即： - 如果真实是点击（\(y_i=1\)），但模型预测 \(\hat y_i\) 很小，此时 \(y_i-\hat y_i > 0\)

    新树会把这个样本的预测分数往上拉

    • 如果真实是未点击（\(y_i=0\)），但模型预测 \(\hat y_i\) 很大，此时 \(y_i-\hat y_i < 0\)

      新树会把这个样本的预测分数往下压

    具体例子

    输入特征为

    x = [召回分数、召回来源、文章热度、文章近期热度、用户历史点击次数、用户活跃度、文章新鲜度、类别偏好匹配度、语言匹配、时间差]

    GBDT 学到的是类似这种规则组合：

    召回分数高 \(\land\) 文章近期热度高 \(\land\) 用户对该类别有偏好 \(\Rightarrow\) 点击概率高

    文章很老 \(\land\) 用户近期活跃度低 \(\land\) 点击概率低 \(\Rightarrow\) 点击概率低

    相较于 LR 的优势：可以通过树的分裂自动形成组合规则，自动学习一些非线性规则和特征组合

    项目中做法

    第 \(m\) 棵树会看所有训练样本：

    \[ (x_{u_1,A},r_{u_1,A}), (x_{u_1,B},r_{u_1,B}), (x_{u_2,C},r_{u_2,C}), \ldots \]

    然后找出一条划分规则，比如 item_strength_sum > 100，让整体的拟合效果最好

    ⑧ 整理成 candidate_pairs，交给精排阶段

    目标：

    • 快速为每个用户生成一个候选文章集合（Candidate Set），供后续排序阶段精排
    • 候选集不要求特别精细，只要保证覆盖用户可能感兴趣的文章即可

    介绍

    召回阶段我使用 YouTubeDNN。首先基于训练集构造用户历史序列，并将用户 ID 和文章 ID 编码成连续索引，方便 embedding

    训练时，用户真实交互文章作为正样本，从未交互文章中采样负样本。模型通过用户 ID embedding 和历史文章 embedding 得到用户兴趣向量，再与文章 embedding 做内积学习匹配分数

    推理时，对每个用户计算其向量，与全量文章向量做内积排序，过滤已读文章后取 Top-K，形成候选集。最后把候选结果整理成 user-item 候选对表，并保留召回排名和召回分数，供后续 DeepFM、xDeepFM、DIN 精排使用

    面试

    在实现上，我用 TensorFlow/Keras 搭建 YouTubeDNN

    项目中的深度模型部分是基于 TensorFlow/Keras 实现的，比如 YouTubeDNN 中，用 tf.keras.Sequential 搭建用户塔，并通过 model.compile 和 model.fit 训练模型。
