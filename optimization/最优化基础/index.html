    函数基础

    广义魏尔斯特拉斯定理

    （Generalized Weierstrass Theorem）

    设 \(f: \mathbb{R}^n \to (-\infty, +\infty]\) 是 proper、下半连续（l.s.c.）且强制的函数，则 \(\text{argmin} f \neq \varnothing\)

    • 即：定理在说最小值点是存在的
    • \(\text{argmin} f = \left\{ x \in \mathbb{R}^n \mid f(x) = \inf_{z \in \mathbb{R}^n} f(z) \right\}\)

    凸分析基础

    def 内点

    给定集合 \(C \subseteq \mathbb{R}^n\)，称 \(x_0\) 为 \(C\) 的内点 \(\Longleftrightarrow\) 存在 \(r > 0\)，使得：

    \[ B(x_0, r) := \{x : \|x_0 - x\| < r\} \subseteq C \]

    用 \(\operatorname{int}(C)\) 表示所有 \(C\) 的内点构成的集合，即：

    \[ \operatorname{int}(C) := \{x_0 : \exists r > 0, B(x_0, r) \subseteq C\} \]

    凸函数

    def 下水平集

    设函数 \(f:C \to (-\infty,+\infty]\)，给定常数 \(c \in \mathbb{R}\)，称集合

    \[ \{x \in C : f(x) \le c\} \]

    为函数 \(f\) 在水平 \(c\) 处的下水平集（sublevel set）

    符号：\(S_c = \{x \in C : f(x) \le c\}\)

    上水平集（superlevel set）

    \[ \{x \in C : f(x) \ge c\} \]

    水平集（level set）

    \[ \{x \in C : f(x) = c\} \]

    def 实值凸函数

    设 \(f: \mathbb{R}^n \rightarrow \mathbb{R}\)，称 \(f\) 为实值凸函数 \(\Longleftrightarrow\) \(\forall x, y \in \mathbb{R}^n\)，\(\forall \theta \in [0,1]\)

    \[ f(\theta x + (1 - \theta)y) \leq \theta f(x) + (1 - \theta)f(y) \]

    研究实例

    （Na Zhang等 - 2022）\(g: \mathbb{R}^n \to \mathbb{R}\)

    def 严格实值凸函数

    设 \(f: \mathbb{R}^n \rightarrow \mathbb{R}\)，称 \(f\) 为严格实值凸函数 \(\Longleftrightarrow\) \(\forall x, y \in \mathbb{R}^n\)，\(\forall \theta \in (0,1)\)

    \[ f(\theta x + (1 - \theta)y) < \theta f(x) + (1 - \theta)f(y) \]
    • 相较于实值凸函数，\([0,1]\) 改为了 \((0,1)\)，不等号 \(\leq\) 改为 \(<\)

    例：凸但不严格凸的

    直线、形如平底锅开口向上的函数

    def 凸集 \(C\) 上的实值凸函数

    Real-valued function over convex set

    设 \(C \subseteq \mathbb{R}^n\) 为凸集，\(f: C \rightarrow \mathbb{R}\)，称 \(f\) 在 \(C\) 上为凸函数 \(\Longleftrightarrow\) \(\forall x, y \in C\)，\(\forall \theta \in [0,1]\)

    \[ f(\theta x + (1 - \theta)y) \leq \theta f(x) + (1 - \theta)f(y) \]
    • Refer：A. Beck 一阶优化 p21

    实值凸函数的连续性

    点情形

    设 \(f:D(f)\to\mathbb{R}\) 为凸函数，若 \(x_0\in \operatorname{int}(D(f))\)，则 \(f\) 在 \(x_0\) 处连续

    • 二维情形的证明可见 notebook 《Convex Analysis》
    推论

    设实值凸函数 \(f:\mathbb{R}^n\to\mathbb{R}\)，则 \(f\) 在 \(\mathbb{R}^n\) 上局部 Lipschitz 连续

    • 在 \(\mathbb{R}^n\) 上局部 Lipschitz 连续：\(\forall x_0 \in \mathbb{R}^n\)，\(\exists L_{x_0} > 0\)，\(\exists r_{x_0} > 0\)，使得 \(\forall x,y \in B(x_0,r_{x_0})\)

      \[ |f(x) - f(y)| \le L_{x_0}\|x-y\| \]

      根据 Lipschitz 连续

    集合情形

    设 \(f:\mathbb{R}^n\to\mathbb{R}\) 为凸函数，则 \(f\) 在 \(\mathbb{R}^n\) 上任意有界集上整体 Lipschitz 连续，即：对任意有界集 \(B\subset\mathbb{R}^n\)，\(\exists L_B>0\)，使得 \(\forall x,y\in B\)

    \[ |f(x)-f(y)| \le L_B \|x-y\| \]

    def 扩展实值凸函数

    extended real-valued convex function

    设 \(f:\mathbb{R}^n \to (-\infty,+\infty]\)，称 \(f\) 为扩展实值凸函数 \(\Longleftrightarrow\) \(\forall x,y \in \mathbb{R}^n\)，\(\forall \theta \in [0,1]\)

    \[ f(\theta x + (1-\theta)y) \le \theta f(x) + (1-\theta)f(y) \]

    def 凸集 \(C\) 上的扩展实值凸函数

    Extended real-valued convex function over convex domain

    设 \(C \subseteq \mathbb{R}^n\) 为凸集，\(f:C\to(-\infty,+\infty]\)，称 \(f\) 在 \(C\) 上为扩展实值凸函数 \(\Longleftrightarrow\) \(\forall x,y\in C\)，\(\forall \theta\in[0,1]\)

    \[ f(\theta x+(1-\theta)y) \le \theta f(x)+(1-\theta)f(y) \]

    例 指示函数

    设 \(S \subseteq \mathbb{R}^n\) 为非空凸集，则指示函数 \(\delta_S\) 是扩展实值凸函数

    Proof：\(\forall x,y \in \operatorname{dom}(\delta_S)=S\)，\(\forall \theta\in[0,1]\)，由于 \(S\) 为凸集，故

    \[ \theta x+(1-\theta)y \in S \]

    因此 \(\delta_S(\theta x+(1-\theta)y)=0\)，代入定义的不等式，得 \(0 \le 0\)，成立 \(\quad \square\)

    指示函数性质

    设 \(C \subseteq \mathbb{R}^n\)，则

    \[ \text{①}\quad \delta_C \text{ 为凸函数} \Longleftrightarrow C \text{ 为凸集} \]
    \[ \text{②}\quad \delta_C \text{ 为闭函数} \Longleftrightarrow C \text{ 为闭集} \]

    Proof：

    ① 由上图定义 \(\operatorname{epi}(\delta_C)=C\times \mathbb{R}_+\)，其中 \(\mathbb{R}_+=[0,+\infty)\)

    \((\Leftarrow)\)

    由于 \(C\) 和 \(\mathbb{R}_+\) 都是凸集，所以它们的直积 \(C\times\mathbb{R}_+\) 为凸集，故 \(\operatorname{epi}\) 为凸集，从而 \(\delta_C\) 为凸函数

    \((\Rightarrow)\)

    已知 \(\operatorname{epi}(\delta_C)=C\times\mathbb{R}_+\) 是凸集，并且 \(\mathbb{R}_+\) 也是凸集

    下面用反证法证明 \(C\) 是凸集：假设 \(C\) 不是凸集，则存在 \(x_1,x_2\in C\) 和某个 \(\theta\in(0,1)\)，使得

    \[ \theta x_1+(1-\theta)x_2\notin C \]

    由 \(x_1,x_2\in C\)，\((x_1,1),\ (x_2,1)\in C\times\mathbb{R}_+\)

    由 \(C\times\mathbb{R}_+\) 为凸集，其凸组合也应属于其中，即

    \[ \theta(x_1,1)+(1-\theta)(x_2,1) = (\theta x_1+(1-\theta)x_2,\ 1) \in C\times\mathbb{R}_+ \]

    这要求

    \[ \theta x_1+(1-\theta)x_2\in C \]

    矛盾

    ② \((\Leftarrow)\)

    同 ① 的证法（闭集与闭集的直积仍为闭集）

    \((\Rightarrow)\)

    反证法：反设 \(C\) 不是闭集，则存在点列 \(\{x_n\}\subset C\)，满足 \(x_n\to x^\ast\)，但 \(x^\ast\notin C\)

    取点列 \(\left \{ (x_n,1) \right \}\)，则 \((x_n,1)\to (x^\ast,1)\)。由于 \(x^\ast\notin C\)，故 \((x^\ast,1)\notin C\times\mathbb{R}_+ = \operatorname{epi}(\delta_C)\)，这与 \(\operatorname{epi}(\delta_C)\) 为闭集矛盾 \(\quad \square\)

    def 实值凹函数

    设 \(f: \mathbb{R}^n \rightarrow \mathbb{R}\)，称 \(f\) 为实值凹函数 \(\Longleftrightarrow\) \(\forall x, y \in \mathbb{R}^n\)

    \[ f(\theta x + (1 - \theta)y) \geq \theta f(x) + (1 - \theta)f(y) \]
    • 与凸仅有不等号的区别

    def 严格实值凹函数

    设 \(f: \mathbb{R}^n \rightarrow \mathbb{R}\)，称 \(f\) 为严格实值凹函数 \(\Longleftrightarrow\) \(\forall x, y \in \mathbb{R}^n\)，\(\forall \theta \in (0,1)\)

    \[ f(\theta x + (1 - \theta)y) > \theta f(x) + (1 - \theta)f(y) \]

    def 凸集 \(C\) 上的凹函数

    设 \(C \subseteq \mathbb{R}^n\) 为凸集，\(f: C \rightarrow \mathbb{R}\)，称 \(f\) 在 \(C\) 上为凹函数 \(\Longleftrightarrow\) \(\forall x, y \in C\)，\(\forall \theta \in [0,1]\)

    \[ f(\theta x + (1 - \theta)y) \geq \theta f(x) + (1 - \theta)f(y) \]

    • 凹函数用的也是凸集

      因为定义里包含了凸组合 \(\theta x+(1-\theta)y\)，为了让这个点仍然属于函数的定义域，需要 \(C\) 为凸集

    单调增函数保持凹性

    设 \(C\) 为凸集，\(f:C \to \mathbb{R}\) 是 \(C\) 上的凹函数，区间 \(I \subseteq \mathbb{R}\)，\(\varphi:I \to \mathbb{R}\) 是 \(I\) 上的凹函数，在 \(I\) 上单调增，

    满足 \(f(C) \subseteq I\)，则

    \[ \varphi \circ f : C \rightarrow \mathbb{R} \]

    在 \(C\) 是凹函数

    次梯度

    def 次梯度

    设 \(f: \mathbb{R}^n \to (-\infty, \infty]\) 为一个 proper 凸函数，设 \(x \in \text{dom}(f)\)，若向量 \(g \in \mathbb{R}^n\) 满足：

    \[ f(y) \geq f(x) + \langle g, y - x \rangle, \quad \forall y \in \mathbb{R}^n \]

    则称 \(g\) 为 \(f\) 在 \(x\) 处的一个次梯度。

    • \(\forall y \in \mathbb{R}^n\) 可写成 \(\forall y \in \operatorname{dom}(f)\)，若 \(y \notin \operatorname{dom}(f)\)，则 \(f(y) = +\infty\)，不等式自动成立

    • 若 \(f(x^*) = + \infty\)，则 \(\partial f(x^*) = \varnothing\)，次梯度要先是选在 \(\text{dom}(f)\) 中的点

    几何意义

    向量 \(g\) 定义了 一个 支撑超平面（Supporting Hyperplane）。该超平面在 \(x\) 点处位于函数图像的下方或切于图像

    def 次微分

    设 \(f:\mathbb{R}^n \to (-\infty,+\infty]\) 为一个 proper 凸函数。对于给定点 \(x\in \mathbb{R}^n\)，称 \(f\) 在 \(x\) 处的次微分（subdifferential）为集合

    \[ \partial f(x) = \{\, g\in \mathbb{R}^n : f(y) \ge f(x)+\langle g, y-x\rangle,\ \forall\, y\in \mathbb{R}^n \,\}. \]
    • 即 \(x\) 处所有次梯度构成的集合称为 \(f\) 在 \(x\) 处的次微分

    凸函数在有界集上的“次梯度一致有界性”

    设 \(g: \mathbb{R}^n \to \mathbb{R}\) 实值凸，\(S \subset \mathbb{R}^n\) 为非空有界集，则：

    ① \(\forall x \in S\)，其次梯度集合 \(\partial g(x)\) 非空

    ② 次梯度并集 \(\bigcup_{x \in S} \partial g(x)\) 是一个有界集。即：存在常数 \(M > 0\)，使得

    \[ \|y\|_2 \leq M, \quad \forall y \in \partial g(x), \forall x \in S \]
    • 该定理可等价表述为：若 \(f\) 实值凸，则在任意有界集上，所有次梯度的范数都可以被一个统一的常数控制

    Fermat's Rule 凸函数的最优性条件

    设 \(f: \mathbb{R}^n \to (-\infty, +\infty]\) proper、凸，则 \(x^*\) 是 \(f\) 的一个全局最优点 \(\Leftrightarrow\)

    \[ 0 \in \partial f(x^*) \]
    • 要 proper，因为若 \(f(x^*) = +\infty\)，那么在该点讨论次梯度 \(0 \in \partial f(x^*)\) 没有意义
    • 若 \(f\) 可微，结论变为 \(0 \in \nabla f(x^*)\)

    Proof：

    ① \((\Leftarrow)\)

    存在次梯度 \(g = 0\) 满足

    \[ f(y) \geq f(x^*) + \langle 0, z - x^* \rangle = f(x^*) \quad \forall y \in \mathbb{R}^n \]

    则 \(x^*\) 为 \(f\) 的一个全局极小值点

    ② \((\Rightarrow)\)

    由全局极小值点定义，可以倒着写刚才的式子，发现 \(g=0\) 是一个次梯度，所以得到结论 \(\quad \square\)

    共轭函数

    Convex Conjugate、Fenchel Conjugate

    设 \(f: \mathbb{R}^n \to (- \infty, \infty]\) 为一函数。其共轭函数 \(f^*: \mathbb{R}^n \to (- \infty, \infty]\) 定义为：

    \[ f^*(y) = \sup_{x \in \text{dom } f} \left\{ \langle y, x \rangle - f(x) \right\} \]

    几何意义：\(f^*(y)\) 可以理解为斜率为 \(y\) 的超平面与函数 \(f(x)\) 图像之间的最大垂直截距

    凸性

    无论原函数 \(f\) 是否为凸函数，\(f^*\) 始终是一个闭凸函数

    二阶共轭 Fenchel-Moreau 定理

    若 \(f\) 是闭凸函数，则 \(f^{**} = f\)

    Fenchel–Young 不等式

    \(\forall x, y \in \mathbb{R}^n\)

    \[ f(x) + f^*(y) \ge \langle x, y \rangle \]

    取等充要条件：

    \[ y \in \partial f(x) \]
    • 即：\(y\) 处于 \(f\) 在 \(x\) 点处的次微分集合中

    取等条件的三等价命题

    若 \(f\) 为闭凸函数，则以下 3 Claims 等价

    ① \(\langle x, y \rangle = f(x) + f^*(y)\)

    ② \(y \in \partial f(x)\)

    ③ \(x \in \partial f^*(y)\)

    Fréchet 次微分

    广义费马引理

    (Generalized Fermat's Rule)

    设 \(f:\mathbb{R}^n \to (-\infty, \infty]\) 为 proper，\(x^* \in \mathbb{R}^n\) 为函数 \(f\) 的局部极小值点（local minimizer），则

    \[ 0 \in \hat{\partial} \varphi(x^*) \]

    • 非光滑优化中的一个基础定理

    • \(\hat{\partial}\) 为 Fréchet subgradient

    • 局部极小值点：存在 \(\delta > 0\)，使得任意满足 \(\|x-x^*\|_2 < \delta\) 的 \(x\)，都有

      \[ f(x^*) \leq f(x) \]

    • 即 \(0\) 必然包含在函数在该点的 Fréchet 次微分中

    下半连续、闭

    def 下半连续

    设函数 \(f: \mathbb{R}^n \to (-\infty, \infty]\)，设 \(x_0 \in \text{dom } f\)，若

    \[ \liminf_{x \to x_0} f(x) \geq f(x_0) \]

    则称 \(f\) 在点 \(x_0\) 处是下半连续的

    拓扑定义

    称函数 \(f: \mathbb{R}^n \to (-\infty, \infty]\) 是下半连续的 \(\Longleftrightarrow\) \(\forall \alpha \in \mathbb{R}\)，其下水平集

    \[ C_\alpha = \{ x \in \text{dom } f \mid f(x) \leq \alpha \} \]

    均为 \(\mathbb{R}^n\) 空间中的闭集

    def 上图

    （Epigraph）

    \[ \text{epi } f = \{ (x, t) \in \mathbb{R}^n \times \mathbb{R} \mid f(x) \leq t \} \]

    def 闭函数

    称函数 \(f: \mathbb{R}^n \to (-\infty, \infty]\) 是闭的 \(\Longleftrightarrow\) 其上图是积空间 \(\mathbb{R}^n \times \mathbb{R}\)（或 \(\mathbb{R}^{n+1}\) ）中的闭集

    基本性质

    下半连续函数之和仍为下半连续

    闭函数的 \(\text{dom}\) 为闭

    设函数 \(f: \mathbb{R}^n \to (-\infty, +\infty]\) 是闭的，则

    \[ \text{dom}(f) = \{x : f(x) < +\infty\} \]

    是闭集

    Lipschitz 连续

    def \(\mathbb{R}^n\) 中某集合上局部 Lipschitz 连续

    设 \(C \subset \mathbb{R}^n\)，\(f: C \to \mathbb{R}^m\)。若 \(\forall x_0 \in C\)，\(\exists r(x_0) > 0\)，常数 \(L_{x_0} > 0\)，使得 \(\forall x, y \in C\cap B(x_0, r(x_0))\)，都有

    \[ \|f(x) - f(y)\| \leq L_{x_0} \|x - y\| \]

    则称 \(f\) 在集合 \(C\) 上是局部 Lipschitz 连续的

    • 一般 \(C\) 为开集

    例：\(f(x) = x^2\) 在全实数集 \(\mathbb{R}\) 上是局部 Lipschitz 连续的，但不是全局 Lipschitz 连续的

    倒数函数保持局部 Lipschitz

    设函数 \(f: \mathbb{R}^n \to \mathbb{R}\)，\(f\) 在点 \(x_0\) 的某个邻域上是局部 Lipschitz 连续的，且满足 \(f(x_0) \neq 0\)。则存在 \(\delta > 0\)，使得 \(\frac{1}{g(x)}\) 在开球 \(B(x_0, \delta)\) 上是全局 Lipschitz 连续的

    （见notability）

    def \(\mathbb{R}^n\) 中某集合上整体 Lipschitz 连续

    设 \(C \subset \mathbb{R}^n\)，\(f: C \to \mathbb{R}^m\)。若 \(\exists L > 0\)，\(\forall x, y \in C\)，有

    \[ \|f(x) - f(y)\| \leq L \|x - y\| \]

    则称 \(f\) 在集合 \(C\) 上是整体（全局） Lipschitz 连续的。

    例 \(\lambda \|x\|_1\) 在 \(\mathbb{R}^n\) 全局 Lips

    设 \(\lambda > 0\)，则 \(f(x) = \lambda \|x\|_1\) 在 \(\mathbb{R}^n\) 上是全局 Lipschitz 连续的

    Sol：

    \(\forall x, y \in \mathbb{R}^n\)，由范数性质

    \[ | \|x\|_1 - \|y\|_1 | \leq \|x - y\|_1 \]

    故

    \[ \begin{aligned} \|f(x) - f(y)\|_2 &= |\lambda \|x\|_1 - \lambda \|y\|_1| \\ &= \lambda | \|x\|_1 - \|y\|_1 | \\ &\leq \lambda \|x - y\|_1 \\ &\leq \lambda \sqrt{n} \|x - y\|_2 \end{aligned} \]

    存在 \(L = \lambda \sqrt{n}\) 满足定义 $ \quad \square$

    \(L\)-smooth

    def \(L\)-smooth 函数、Lipschitz Differentiable

    设函数 \(f:\mathbb{R}^n \to \mathbb{R}\) 可微，若存在常数 \(L>0\)，使得 \(\forall x,y\in\mathbb{R}^n\) 都有

    \[ \|\nabla f(x)-\nabla f(y)\|_2 \le L\|x-y\|_2 \]

    则称\(f\) 是Lipschitz 可微函数 （Lipschitz continuously differentiable），或 \(\nabla f\) 是 Lipschitz 连续，或 \(f\) 是 \(L\)-smooth

    下降引理

    设函数 \(f: \mathbb{R}^n \to \mathbb{R}\) 是 \(L\)-smooth，则 \(\forall x, y \in \mathbb{R}^n\)，有

    ① 上界估计

    \[ f(x) \le f(y) + \langle \nabla f(y), x - y \rangle + \frac{L}{2} \|x - y\|_2^2 \]

    ② 下界估计

    \[ f(x) \ge f(y) + \langle \nabla f(y), x - y \rangle + \frac{1}{2L} \|\nabla f(x) - \nabla f(y)\|_2^2 \]

    梯度 Lipschitz 连续性的二阶刻画

    设 \(C\subset \mathbb{R}^n\) 为开集，\(f:C\to \mathbb{R}\) 为二阶连续可微函数，即 \(f \in C^2(\Omega)\)，则以下两个命题等价：

    ① 存在常数 \(L>0\)，使得 \(\forall x,y\in C\)

    \[ \|\nabla f(x)-\nabla f(y)\| \le L\|x-y\| \]

    ② 存在常数 \(L>0\)，使得 \(\forall x\in C\)

    \[ \|\nabla^2 f(x)\|\le L \]

    在上述条件下，梯度的最小 Lipschitz 常数满足

    \[ \inf \Big\{ L>0:\, \|\nabla f(x)-\nabla f(y)\| \le L\|x-y\|, \ \forall x,y\in\Omega \Big\} = \sup_{x\in\Omega} \|\nabla^2 f(x)\| \]
    • 定理说明 $ \nabla f \text{ Lipschitz } \Longleftrightarrow \nabla^2 f$ 有界，并且 \(L = \sup_{x\in\Omega}\|\nabla^2 f(x)\|\) 就是梯度 Lipschitz 常数

    def 局部 Lipschitz 可微函数

    （Locally Lipschitz Differentiable）

    设 \(\Omega \subset \mathbb{R}^n\)，\(C\subset\Omega\)，函数 \(f:\Omega \to \mathbb{R}\)。若 \(\forall x\in C\)，存在常数 \(L_x>0\) 与 \(\delta_x>0\)，使得

    ① \(f \in C^1(B(x,\delta_x))\)；

    ② \(\forall u,v\in B(x,\delta_x)\) 都有

    \[ \|\nabla f(u)-\nabla f(v)\|_2 \le L_x\|u-v\|_2 \]

    则称 \(f\) 在 \(C\) 上局部 Lipschitz 可微（locally Lipschitz differentiable around each point in \(C\)），或称 \(\nabla f\) 在 \(C\) 上局部 Lipschitz 连续。

    • 同时有 \(C,\Omega\) 的原因：若 \(C = \Omega\)，则 \(f\) 在整个定义域上处处局部 Lipschitz 可微。若不然，\(C\) 只是 \(\Omega\) 的一部分，\(f\) 在 \(C\) 以外的地方可以非常“狂野”，甚至不可微

    全局可微与局部的关系

    全局 \(\Longrightarrow\) 局部，在全空间中，梯度的变化被 \(L\) 控制住了，在小的邻域内，也可以被同一个常数 \(L\) 控制

    邻近算子

    def 邻近算子

    设函数 \(f:\mathbb{R}^n\to(-\infty,+\infty]\) 为 proper、下半连续、凸函数，给定参数 \(\lambda>0\)。\(\forall v\in\mathbb{R}^n\)，定义 \(f\) 的邻近算子为

    \[ \operatorname{prox}_{\lambda f}(v) = \arg\min_{x\in\mathbb{R}^n} \left\{ f(x)+\frac{1}{2\lambda}\|x-v\|_2^2 \right\} \]

    邻近算子的最优性刻画

    设函数 \(f:\mathbb{R}^n \to (-\infty,+\infty]\) 为 proper、下半连续、凸函数，\(\lambda>0\)，\(v\in\mathbb{R}^n\)。则向量 \(x^\ast\) 满足

    \[ x^\ast=\operatorname{prox}_{\lambda f}(v) \]

    当且仅当

    \[ v \in x^\ast + \lambda \partial f(x^\ast). \]

    等价地，上述条件也可以写为

    \[ 0 \in \partial f(x^\ast)+\frac{1}{\lambda}(x^\ast-v). \]

    例 应用于软阈值算子

    \[ x = \text{soft}(v,\lambda) \quad \Longleftrightarrow \quad v \in x+\lambda \partial\|x\|_1 \]

    软阈值算子

    取 \(f(x)=\|x\|_1\)，软阈值算子符号定义为

    \[ S_\lambda(v) = \operatorname{soft}(v,\lambda) = \operatorname{prox}_{\lambda \|\cdot\|_1}(v) \]

    标量情形

    标量 \(v \in \mathbb{R}\)，设 \(\lambda \ge 0\)，软阈值算子 \(S_{\lambda}(v)\) 定义为

    \[ S_{\lambda}(v) = \begin{cases} v - \lambda, & v > \lambda \\ 0, & |v| \le \lambda \\ v + \lambda, & v < -\lambda \end{cases} \]

    向量情形

    设向量 \(v = (v_1, v_2, \dots, v_n)^\top\)，其软阈值结果 \(S_{\lambda}(v)\) 的第 \(i\) 个分量为

    \[ (S_{\lambda}(v))_i = \begin{cases} v_i - \lambda, & v_i > \lambda \\ 0, & |v_i| \le \lambda \\ v_i + \lambda, & v_i < -\lambda \end{cases} \quad i=1,2,\dots,n \]
